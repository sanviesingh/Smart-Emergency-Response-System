# Smart-Emergency-Response-System
A smart emergency response and resource allocation system using DSA in C and OOP in C++.
## LifeLine – Emergency Response System

## Problem Statement
Multiple emergencies may occur simultaneously while available resources are limited. The system prioritizes emergencies, allocates available resources and determines efficient routes.

## Objectives
- Emergency reporting
- Priority-based emergency handling
- Resource allocation
- Route planning
- Response tracking
