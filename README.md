# LifeLine – Smart Emergency Response System

## Problem Statement

Multiple emergencies may occur simultaneously while available
resources such as ambulances and responders are limited.
LifeLine provides a structured approach to prioritize emergencies,
allocate resources and determine efficient response routes.

## Objectives

- Record emergency information
- Prioritize critical emergencies
- Allocate available resources
- Find efficient routes
- Track response status
- Demonstrate integration of DSA and OOP
